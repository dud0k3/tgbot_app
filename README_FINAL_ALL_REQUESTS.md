# SYNDICATE v14 FINAL — all requests

Эта сборка собрана под GitHub + Dockhost.

## Что включено

- Telegram bot + FastAPI backend + TG Mini App в одном Docker-контейнере.
- Быстрый Docker build для Dockhost через multi-stage `node:20-alpine` + `python:3.11-slim`.
- Frontend отдаётся на `/`.
- API работает на `/api/...`.
- Кнопка `SYNDICATE` из клавиатуры бота удалена.
- Кнопка `⬅️ Назад` сбрасывает любое состояние и возвращает в главное меню.
- База не сбрасывается при Redeploy при подключении сетевого диска `/data`.
- Товары списываются со склада только после подтверждения заказа админом.
- При создании заказа товар из каталога не пропадает до подтверждения.
- Админские кнопки подтверждения/отмены заказа работают.
- Заказы разделяются по дням.
- Верхняя картинка TG App заменена на SYNDICATE-баннер.
- Шрифт заменён на обычный системный.
- Корзина:
  - Самовывоз — бесплатно.
  - МЦД-3 — 100 ₽.
  - Цена доставки суммируется с итогом.
  - Самовывоз выбирается кнопками:
    - Ипподром
    - Раменское
    - Фабричная
    - Есенинская
    - Кратово
    - Отдых
  - МЦД-3: покупатель сам пишет станцию.
  - Курьер, СДЭК, адрес в Москве и дата убраны.
- Админу в заказ приходит:
  - способ получения;
  - стоимость получения;
  - пункт самовывоза или станция МЦД-3;
  - итоговая сумма.

## Dockhost variables

Создать отдельными переменными:

```env
BOT_TOKEN=НОВЫЙ_ТОКЕН_ОТ_BOTFATHER
ADMINS=1364205492,861098409
ORDER_GROUP_ID=0
WEBAPP_URL=https://jr7p-h2em-cr2a.gw-1a.dockhost.net
DB_PATH=/data/bot.db
```

## Dockhost volume

Подключить сетевой диск к контейнеру:

```text
Mount path: /data
```

## Dockhost port and route

```text
Container port: 8000/TCP
Domain route path: /
Service: tgbot
Port: 8000
```

После загрузки на GitHub нажать в Dockhost именно:

```text
Redeploy / Пересобрать
```

Не просто Restart.
