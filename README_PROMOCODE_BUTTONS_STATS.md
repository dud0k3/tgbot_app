Что изменено:
1. Кнопка «🎟 Промокод» больше не запускает сразу ввод нового промокода.
2. При нажатии на «🎟 Промокод» показывается статистика по действующим промокодам.
3. В статистике показывается: количество действующих промокодов, безлимитные, лимитные, всего использований и остаток использований по лимитным.
4. Ниже выводится список действующих промокодов с процентом и лимитом.
5. Добавлены отдельные inline-кнопки: «➕ Добавить промокод» и «🗑 Удалить промокод».
6. Удаление можно сделать выбором промокода из списка или ручным вводом кода.
7. После создания или удаления промокода бот снова показывает актуальную статистику.
8. Автоудаление промокода после последнего использования сохранено.
