# System font update

Шрифт в TG App заменён на обычный системный:
- iOS/macOS: San Francisco
- Android/Windows: стандартный системный sans-serif
- fallback: Arial

Убран импорт Space Grotesk.
Добавлен override, который отключает футуристичные letter-spacing и делает вид ближе к обычному Telegram Mini App.
