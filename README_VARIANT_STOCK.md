Что добавлено:
1. У каждого варианта/вкуса теперь есть отдельный остаток на складе.
2. Админ при добавлении товара вводит варианты в формате: Вкус:количество.
3. Пример: Яблоко:10, Груша:5, Манго:0.
4. В админке через «✏️ Редактировать варианты» можно менять остатки вкусов уже существующего товара.
5. Админ видит остатки вкусов в списке редактирования.
6. Вкус с остатком 0 автоматически скрывается из карточки товара у покупателя.
7. Если у товара все вкусы закончились, общий остаток товара становится 0, и товар пропадает из выдачи.
8. При добавлении в корзину backend проверяет остаток именно выбранного вкуса.
9. При подтверждении заказа админом остаток списывается именно с выбранного вкуса.
10. Старые товары со старыми вариантами без остатков не ломаются: их варианты временно используют общий остаток товара.
11. Чтобы перевести старый товар на новый формат, открой «✏️ Редактировать варианты» и введи вкусы с количеством.
