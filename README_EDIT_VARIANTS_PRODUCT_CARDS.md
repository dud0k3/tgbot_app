# Edit variants + clean product cards

Что добавлено:

1. Редактирование вариантов у существующего товара:
   - Админка → ✏️ Редактировать варианты
   - выбрать товар
   - отправить варианты через запятую или с новой строки
   - отправить `-`, чтобы удалить варианты.

2. Варианты товара:
   - при добавлении товара теперь можно указать варианты;
   - при открытии товара покупатель выбирает вариант;
   - вариант сохраняется в корзине;
   - вариант уходит админу в заказ.

3. Карточки товаров:
   - дизайн сделан ближе к референсу;
   - большая квадратная картинка сверху;
   - название и цена ниже;
   - широкая кнопка “Добавить”;
   - если товар уже в корзине без вариантов — показывается счетчик `− 1 +`.

4. Картинки товаров и категорий:
   - увеличены;
   - меньше обрезаются;
   - используется `object-fit: contain`.
