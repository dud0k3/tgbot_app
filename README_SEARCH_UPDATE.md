# Поиск в TG App

Добавлено:
- поиск по категориям;
- поиск по товарам внутри выбранной категории;
- счётчик найденных категорий/товаров;
- кнопка очистки поиска.

Замени:

```text
frontend/src/App.jsx
frontend/src/style.css
```

Потом перезапусти frontend:

```bash
cd ~/Desktop/simple_shop_bot/frontend
npm run dev
```
