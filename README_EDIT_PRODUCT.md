Что добавлено:
1. В админке появилась кнопка «✏️ Редактировать товар».
2. Добавлена команда /edit_product.
3. Админ выбирает товар из списка.
4. После выбора товара можно изменить: название, описание, цену, остаток, категорию, фото, вкусы/варианты.
5. Фото можно заменить новым фото или удалить, отправив '-'.
6. Описание можно очистить, отправив '-'.
7. Если у товара есть вкусы, остаток редактируется через остатки вкусов.
8. Если товар без вкусов, остаток редактируется обычным числом.
9. Вкусы/варианты редактируются в формате: Яблоко:10, Груша:5, Манго:0.
10. Вкус с остатком 0 скрывается у покупателя.
