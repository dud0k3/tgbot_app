Что сделано:
1. При открытии Mini App пользователь автоматически регистрируется в базе бота.
2. Frontend сразу вызывает POST /api/register при запуске приложения.
3. Backend регистрирует пользователя при любом авторизованном запросе из Mini App.
4. Если пользователь открыл приложение по реферальной ссылке, start_param сохраняется в bonus_accounts.referrer_id.
5. Реферальная ссылка теперь ведет прямо в Mini App: https://t.me/BOT_USERNAME/MINI_APP_NAME?startapp=ref_CODE.
6. Добавлена переменная MINI_APP_NAME. По умолчанию используется app.
7. Если в BotFather short name Mini App другой, укажи в Dockhost MINI_APP_NAME=нужное_имя.
8. Важно: Telegram не разрешает боту писать пользователю, если он вообще не открывал чат/бота. Но для заказов, бонусов и рефералок пользователь теперь регистрируется в базе при открытии Mini App.
