Что сделано:
1. Картинки теперь сохраняются не только как Telegram file_id, но и локально в data/uploads.
2. В базе добавлены поля categories.image_path и products.photo_path.
3. API сначала отдаёт локальную картинку /uploads/..., и только если её нет — старый /api/tg-file.
4. FastAPI раздаёт папку /uploads как статические файлы, поэтому картинки грузятся быстрее.
5. При переносе на нового бота новые картинки не пропадут, если переносить вместе с папкой data/uploads и database.sqlite.
6. При добавлении новой категории/товара фото сразу скачивается с Telegram и сохраняется локально.
7. Добавлена команда /cache_images для переноса уже существующих картинок из Telegram file_id в локальные файлы.
8. Если картинки были загружены старым ботом, в Dockhost временно укажи OLD_BOT_TOKEN=старый_токен и выполни /cache_images.
9. Если старого токена нет, старые картинки восстановить автоматически нельзя — нужно заново загрузить фото через админку.

Рекомендации для Dockhost volume:
- сохранять database.sqlite
- сохранять data/uploads
- не хранить data/uploads только внутри одноразового контейнера, иначе при пересборке картинки могут пропасть.
