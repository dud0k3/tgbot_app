# SYNDICATE TG App v9 — Premium Vape Design

Реализовано:
- Space Grotesk;
- тёмная палитра: #02021A, #0E0820, #6C2DBA, #A06FC2, #D0B5DC;
- плавное свечение вокруг логотипа;
- товары 2×2;
- квадратные карточки товаров;
- фото занимает почти всю верхнюю часть карточки;
- маленькая кнопка `+` в углу карточки;
- скругления 24px;
- фиолетовые тени;
- анимация увеличения карточек и кнопок при нажатии;
- поиск;
- сортировка одной кнопкой;
- нижняя навигация.

Замени папку:

```text
frontend
```

или только:

```text
frontend/src/App.jsx
frontend/src/style.css
frontend/public/syndicate-logo.png
frontend/vite.config.js
```

Потом перезапусти:

```bash
cd ~/Desktop/simple_shop_bot/frontend
npm install
npm run dev
```
