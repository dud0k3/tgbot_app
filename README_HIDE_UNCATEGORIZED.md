# Hide Uncategorized category

Что сделано:
1. Категория `Без категории` скрыта из каталога для покупателя.
2. Категория не отображается в поиске категорий.
3. Категория не отображается в верхних вкладках при просмотре товаров.
4. Логика админки и база не удалялись: товары и сама категория физически не стираются.
