Начисление 2% теперь рассчитывается только от стоимости товаров.

- Стоимость доставки не входит в базу начисления.
- Доплата 100 рублей за заказ день-в-день не входит в базу начисления.
- Расчёт выполняется только после подтверждения заказа.
- Сумма всегда рассчитывается напрямую из позиций order_items.
- При запуске автоматически исправляются старые ошибочные начисления и баланс пользователя.
