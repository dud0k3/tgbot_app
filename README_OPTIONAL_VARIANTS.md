Что исправлено:
1. Вкус/вариант теперь явно необязательный.
2. При добавлении товара админ может написать '-' или 'нет', если товар без вкусов.
3. При редактировании существующего товара админ может написать '-' или 'нет', чтобы полностью убрать вкусы.
4. Товары без вкусов добавляются в корзину без выбора варианта.
5. Товары со вкусами по-прежнему требуют выбор вкуса.
6. Вкус с остатком 0 скрывается у покупателя.
7. Старые товары с вариантами без указанных остатков больше не скрывают вкусы: они используют общий остаток товара как fallback.
