Что сделано:
1. После оформления заказа покупателю автоматически приходит уведомление в Telegram-бот.
2. Первым сообщением отправляется фиолетовая фирменная картинка в стилистике магазина с надписью «Спасибо за заказ!».
3. Следующим сообщением отправляется информация о заказе:
   - номер заказа
   - что заказано
   - сумма заказа
   - способ получения
   - пункт самовывоза или станция МЦД-3
4. Уведомление отправляется именно после оформления заказа, а не после подтверждения админом.
