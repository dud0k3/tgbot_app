Что добавлено:
1. У промокода появилось количество использований.
2. При создании промокода админ вводит: название → процент → количество использований.
3. 0 использований означает без ограничения.
4. В админском списке промокодов показывается использовано/лимит, например 3/10 или 3/∞.
5. Когда промокод применяется в заказе, used_count увеличивается на 1.
6. Если лимит закончился, покупатель получает ошибку: промокод закончился или отключён.
7. Если заказ отменён, использование промокода возвращается: used_count уменьшается на 1.
8. Скидка по промокоду теперь действует на товары + доставку.
9. Backend заново проверяет лимит промокода при оформлении заказа.
10. Frontend пересчитывает скидку от суммы товаров + доставки.
