# Fixed product modal

Что исправлено:

1. Картинка в карточке товара больше не перекрывает название, варианты и кнопку.
2. Модальное окно разделено на две зоны:
   - верхняя зона только для изображения;
   - нижняя зона для названия, описания, вариантов, цены и кнопки.
3. На мобильной версии окно стало аккуратным bottom-sheet.
4. На ПК окно центрируется и не вылезает за экран.
5. Варианты товара переносятся по строкам и не залезают друг на друга.
