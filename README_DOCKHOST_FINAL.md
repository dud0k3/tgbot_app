# SYNDICATE bot v14 — готово для GitHub + Dockhost

В архиве готовая версия:
- Telegram bot + FastAPI API в одном Docker-контейнере;
- TG Mini App v14 из `frontend`;
- заказы разделяются по дням в боте;
- админ-кнопки подтверждения/отмены работают;
- товар НЕ списывается со склада при создании заказа, списывается только после подтверждения админом;
- backend отдаёт собранный `frontend/dist` на `/`;
- база создаётся автоматически при старте.

## Что НЕ входит в архив

Токен бота не включён. Его нужно добавить в Dockhost переменными окружения.

## Переменные Dockhost

```env
BOT_TOKEN=НОВЫЙ_ТОКЕН_ОТ_BOTFATHER
ADMINS=1364205492,861098409
ORDER_GROUP_ID=0
WEBAPP_URL=https://ТВОЙ-ДОМЕН.dockhost.net
```

## Dockhost

Контейнер:
- Dockerfile path: `Dockerfile`
- Context: `.`
- Port: `8000/TCP`

Маршрут:
- Домен: твой динамический домен
- Путь: `/`
- Тип: внутренний
- Сервис: `tgbot`
- Порт: `8000`

После deploy открой:
```text
https://ТВОЙ-ДОМЕН.dockhost.net
```

Если видишь приложение — всё готово.
