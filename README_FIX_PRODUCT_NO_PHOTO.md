Исправлена обработка добавления товара без фото.

Причина: отдельный FSM-хендлер для состояния AddProduct.photo перехватывал текстовые сообщения до основного хендлера добавления товара без фото. Поэтому сообщение '-' обрабатывалось как неподдерживаемый тип контента и товар не создавался.

Что исправлено:
- '-' теперь корректно добавляет товар без фото;
- также поддержаны варианты: —, –, −, нет, no;
- редактирование товара: '-' корректно удаляет фото;
- добавление категории без картинки также устойчиво обрабатывает skip-текст;
- фото товара по-прежнему сохраняется как раньше;
- неправильные типы файлов/стикеры по-прежнему получают понятную ошибку.
