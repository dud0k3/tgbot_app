# Компактные товары + сортировка одной кнопкой

Изменено:
- товары отображаются по 2 в ряд;
- карточки стали компактнее;
- сортировка работает одной кнопкой:
  - Сортировать по цене
  - Сначала дешевле
  - Сначала дороже

Замени:

```text
frontend/src/App.jsx
frontend/src/style.css
```

Потом перезапусти frontend:

```bash
cd ~/Desktop/simple_shop_bot/frontend
npm run dev
```
