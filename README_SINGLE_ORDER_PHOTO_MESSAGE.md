Что сделано:
1. После оформления заказа покупателю приходит одно сообщение.
2. В одном сообщении теперь: картинка + «Спасибо за заказ!» + детали заказа.
3. Второе отдельное сообщение с деталями заказа больше не отправляется.
4. Если Telegram по какой-то причине не примет картинку, бот отправит одно текстовое сообщение с деталями.
5. Логика подтверждения заказа админом и начисления бонусов не изменялась.
