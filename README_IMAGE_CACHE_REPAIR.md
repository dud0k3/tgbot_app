Что исправлено/добавлено:
1. Если image_path есть в базе, но сам файл data/uploads исчез после деплоя, API больше не отдаёт битую /uploads ссылку.
2. /cache_images теперь повторно кэширует картинки, если локальный файл отсутствует, даже если image_path был записан в базе.
3. Добавлена команда /images_status — показывает, сколько картинок реально лежит локально.
4. Добавлен endpoint /api/debug/images?token=DEBUG_TOKEN.
5. Если OLD_BOT_TOKEN не указан, а file_id принадлежит старому боту, скачать старые картинки невозможно — Telegram не даст доступ новому боту.
6. В таком случае надо временно указать OLD_BOT_TOKEN старого бота и выполнить /cache_images, либо загрузить фото заново.
7. Для будущих переносов обязательно переносить database.sqlite и папку data/uploads.
