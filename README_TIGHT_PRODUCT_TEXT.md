# Tight product card text spacing

Что сделано:
1. Уменьшен разрыв между названием товара и строкой `Есть варианты`.
2. Убрана принудительная минимальная высота у названия товара.
3. Подравнены отступы внутри карточки товара.
4. Цена теперь стоит ближе и аккуратнее относительно названия/вариантов.
5. Остальная логика и дизайн не изменялись.
