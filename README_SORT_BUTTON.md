# Сортировка одной кнопкой

Сортировка теперь работает одной кнопкой:

```text
↕ Сортировать по цене
→ Сначала дешевле
→ Сначала дороже
→ Сортировать по цене
```

Замени:

```text
frontend/src/App.jsx
frontend/src/style.css
```

Потом перезапусти frontend:

```bash
cd ~/Desktop/simple_shop_bot/frontend
npm run dev
```
