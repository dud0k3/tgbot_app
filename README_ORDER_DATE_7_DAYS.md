# Order date selector: 7 days

Добавлено отображение 7 дат: сегодня + следующие 6 дней.
Даты обновляются по московскому времени: frontend пересчитывает дату при открытии корзины и проверяет смену дня каждую минуту; backend дополнительно проверяет дату при создании заказа.
День-в-день по-прежнему добавляет +100 ₽.
