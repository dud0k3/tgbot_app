# Polished symmetry

Что сделано:
1. Подравнены карточки товаров и категорий.
2. Сделаны более симметричные отступы.
3. Уменьшены крупные надписи.
4. Уменьшены шрифты в карточке товара, корзине, заказах и оформлении.
5. Подправлены кнопки, нижняя панель и блоки выбора вариантов.
6. Сохранён фиолетовый стиль.
