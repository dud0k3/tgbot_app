# SYNDICATE v14 FINAL VISIBLE CHECKOUT

Эта версия специально исправляет проблему, когда в корзине не отображался выбор способа получения.

В корзине обязательно отображается:
- Способ получения
  - Самовывоз — бесплатно
  - МЦД-3 — 100 ₽
- При самовывозе: кнопки станций Ипподром, Раменское, Фабричная, Есенинская, Кратово, Отдых.
- При МЦД-3: текстовое поле для станции.
- Стоимость доставки суммируется с итогом заказа.
- Backend сам считает доставку, даже если frontend отправит неправильную цену.

Если после деплоя всё равно видишь старую корзину без доставки, значит Telegram/Dockhost показывает старую сборку:
1. Сделай именно Redeploy/Пересобрать.
2. Закрой Mini App полностью.
3. В Telegram открой меню приложения → три точки → перезагрузить/открыть заново.
