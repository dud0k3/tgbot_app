Что изменено:
1. Промокоды теперь можно удалять полностью.
2. В админке «🎟 Промокод» команда del CODE теперь удаляет промокод из базы, а не просто выключает.
3. Дополнительно работают варианты: delete CODE, rm CODE, remove CODE.
4. Если у промокода есть лимит использований, то после последнего использования он автоматически удаляется из таблицы promocodes.
5. Промокод по-прежнему считается использованным только после подтверждения заказа админом.
6. Старые отключённые или уже исчерпанные промокоды очищаются автоматически при открытии списка промокодов или проверке промокода.
7. Информация о промокоде в уже созданных заказах сохраняется в orders: promo_code, promo_percent, promo_discount.
