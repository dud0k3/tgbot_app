4. Если у покупателя остались старые кнопки из кэша Telegram, после нажатия бот удалит клавиатуру.
5. Mini App кнопка APP не тронута — это системная кнопка Telegram.
6. Авто-регистрация пользователей из Mini App и реферальные ссылки сохранены.
7. Уведомления админам о заказах сохранены.
