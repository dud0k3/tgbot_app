# Редактирование категорий в админке

Добавлено:
- кнопка `✏️ Редактировать категорию` в админке;
- команда `/edit_category`;
- выбор категории из списка;
- редактирование названия категории;
- редактирование эмодзи категории;
- замена картинки категории;
- удаление картинки категории через `-`.

Изменённые данные сразу сохраняются в SQLite и начинают отображаться в каталоге Mini App после обновления списка категорий.
